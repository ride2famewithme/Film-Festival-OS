# Vision

Film Festival OS™ is a next-generation AI-powered software platform designed to simplify every aspect of running a film festival.

Instead of juggling multiple systems, Film Festival OS™ brings submissions, judging, awards, media management, websites, communications, and reporting together in one intuitive platform.

---

# Mission

To provide film festivals around the world with an intelligent, easy-to-use operating system that saves time, improves transparency, and enhances the festival experience for organisers, filmmakers, sponsors, and audiences.
